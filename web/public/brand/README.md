# Official logo goes here

Place the official MAVRIX FIRE logo as **`logo.png`** in this folder (square PNG, ideally 512×512 or larger,
transparent background). The app uses this one file everywhere (splash, headers, favicon, PWA/Android icon)
and never redraws, recolours or distorts it.

Until the file is added the UI shows the plain text "MAVRIX FIRE" in place of the image — no substitute logo is drawn.
